# 長洲社區保育考察

從社區保育看可持續發展 — 實地考察網頁。

## 使用

- 學生頁：打開 `index.html`
- 老師後台：頁面右上角「老師」→ 用 `@caritasfsc.edu.hk` Google 登入
- 查看提交結果：後台 →「查看提交」（直接讀 Firebase，不依賴 Google Sheet）

## 檔案

- `index.html`：完整考察網站（含老師結果頁）
- `Code.gs`：可選的 Google Apps Sheet 備份腳本

## GitHub Pages

Repo Settings → Pages → Deploy from branch `main` / root
